LAB11 / UNITY 2021 DESKTOP

打包发布与作品提交

本实验在你本机安装的 Unity 2021.3 编辑器中完成，不在网页实验台内模拟构建过程。教师按提交的成果文件与量规人工评定。

PC 版本步骤

  1. 打开自己的 3D 项目，运行一次场景，确认 Console 没有 Error。
  2. 选择 File → Build Settings，目标选 Windows, Mac, Linux；点击 Switch Platform。
  3. 在 Scenes In Build 中加入启动场景；设置输出文件夹后点击 Build。
  4. 运行生成的 exe，截取启动、核心交互和结束画面。

WebGL 版本步骤

  1. 在 Build Settings 选择 WebGL 并 Switch Platform（需已安装 Unity 2021 WebGL Build Support）。
  2. Player Settings 中确认产品名、分辨率与发布设置；点击 Build。
  3. 用本地 HTTP 服务或学校服务器访问生成目录，不能直接双击 index.html。

提交清单

  • 项目或构建成果压缩包（ZIP / unitypackage）；
  • 至少 3 张运行截图，或一段演示视频；
  • 简要说明：目标平台、核心功能、已知问题、素材来源与授权情况。

如何上传：进入“我的任务”，打开老师发布的“实验11”任务，在提交弹窗选择成果文件。单个文件最大 200MB，最多 5 个；文件为私有存储，仅本人和本班教师可下载。

支持 ZIP、unitypackage、Word、PDF、图片、MP4、TXT、JSON；平台不会执行或解压上传文件。
