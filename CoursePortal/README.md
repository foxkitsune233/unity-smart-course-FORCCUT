# Unity研习室：B1可运行版本

本机入口：[学生首页](http://127.0.0.1:8090/) · [学生任务页](http://127.0.0.1:8090/tasks.html) · [教师端](http://127.0.0.1:8090/teacher.html) · [教师教学流程](http://127.0.0.1:8090/teaching.html) · [管理员](http://127.0.0.1:8090/admin.html)。Unity2021实验现使用同站 http://127.0.0.1:8090/lab/，无需另启8088服务，Unity工程未改动。

在 `D:\unity` 运行，使用支持 `node:sqlite` 的Node24：

```powershell
node .\CoursePortal\serve.mjs
```

无需安装npm依赖。Node24当前会输出SQLite实验特性提示。服务绑定本机127.0.0.1，默认端口8090，可通过 `PORT` 改端口。

## 账号与数据

首次启动随机生成admin、teacher、student三个本机账号，密码保存在 `D:\unity\.course-portal-data\local-accounts.txt`，不会由网站提供下载。请从该文件取密码登录。已有数据再次启动时不会重置账号或课程。

SQLite数据库为 `D:\unity\.course-portal-data\portal.sqlite`，位于网站根目录之外。可用 `PORTAL_DATA_DIR` 指定其他私有目录。备份时停止服务并备份整个数据目录；不要只复制运行中的主数据库文件而忽略WAL。

管理员管理账号和审计；初始teacher是Unity课程负责人。课程负责人可编辑、发布及授权成员，课程教师可编辑，助教只读；学生不能进入教师空间。平台管理员不会自动获得课程草稿权限。密码使用scrypt哈希，会话使用HttpOnly Cookie，写入校验CSRF和来源；停用账号会撤销会话。

## 已可操作的流程

1. 教师登录，在工作台进入课程管理，或新建课程。
2. 编辑课程信息、待确认学时、专业育人说明、独立教学目标、章节和多个课时。每课时分别关联视频资源标识、HTTP/HTTPS地址及实操入口。
3. 保存草稿，刷新后仍保留。多窗口保存冲突时保留输入，并提供本地草稿下载及重新载入。
4. “预览当前输入”查看未保存表单；“预览已保存草稿”打开有权限的学生视角预览。
5. 确认学时、目标与章节后发布。学生读取发布快照，后续草稿修改不会改变学生正在学习的版本。
6. 负责人通过课程成员页授权已有教师或助教；管理员创建、启停账号并查看真实操作审计。

## 教学流程（教学班 → 任务 → 提交 → 批阅 → 学情）

教师端「教学流程」页（`teaching.html`）与学生端「我的任务」页（`tasks.html`）构成一条完整教学闭环。

- **教学班**：绑定已发布课程与学期，可导入学生名单。名单按「学号, 姓名, 账号, 分组」逐行粘贴，导入前先出预览，把「可入班 / 重复 / 找不到账号 / 格式问题」四类分开列出，确认后才入班；重复导入不重复入班，离班保留原有提交与评分证据。
- **任务下发**：任务先存草稿（可改），发布后规则锁定。可见类型为实验实训 / 实践作业 / 在线测验 / 实验报告；可设满分、总评占比、开放与截止时间、最大提交次数、是否允许补交与重做、关联课时与实验、育人要求。
- **量规批阅**：评分维度在任务内配置，维度权重合计须为 100%、维度满分之和须等于任务满分（服务端再次校验）。教师逐维度打分后写评语，选择是否发布给学生。
- **权重分两层**：第一层是任务内各评分维度的权重，第二层是该任务在课程总评中的占比。两者不共用字段，也不替教师填比例；合计不足时界面显式提示"尚未配置完整"，不擅自补齐。
- **改分留痕**：改分必须填理由，写入 `score_revisions`，记录改分前后分值、操作者与时间，教师端可见改分日志。
- **班级学情**：四种完成口径分列互不替代——自报已学、视频结束、实验通过、教师确认。统计分母只含本班已下发的任务，缺失记录不计为完成，未下发任务不计入分母。
- **成绩导出**：按班导出成绩 CSV，含各任务分数、已提交数、已批阅数与平均分。

权限：班负责人可导入名单、发布任务、批阅、改分与导出；授课教师可发布任务与批阅；助教当前不能批阅与改分；学生只能看到自己所在教学班的已发布任务，且只能看到已发布给本人的成绩。

学习记录（进度与笔记）现已按账号隔离：存储键包含用户 id，旧的无账号维度记录只做一次性迁移并带来源标记，不会被第二个账号继承；服务端另有 `learning_records` 按账号落库。

Unity课程现按学校教学计划组织为11个教学章节、12个必修学习单元：章节教学44学时，期中上机2学时、期末作品答辩2学时，共48学时。特效与音频归入CH07，资源管理与热更新另设2学时选学专题，不计入48学时与必修进度。首页、视频页支持搜索、筛选、前后课时、导学、随堂笔记与Unity实验入口。

## 视频与学习记录的边界

当前Unity课程的88条视频引用已与本机87个分集建立对应。视频文件位于 D:/unity/CourseVideos，服务器按白名单提供 /media/资源ID.mp4 地址，支持GET、HEAD和HTTP Range拖动进度；不把整个磁盘目录开放成静态目录。已有本地源优先播放，保留作者、版本说明及原站链接。教师课程编辑区显示“本地可播放”。

服务端通过运行时附加localSrc替换播放来源，不修改课程草稿或不可变发布快照。映射配置为 server/local-media-map.json；只作用于当前unity-script-2021课程。源文件完整性报告位于 outputs/Unity视频批量下载/local-video-audit.json。29个HEVC文件在本机浏览器仅有声音，需由 Tools/prepare-local-web-videos.mjs 生成经验证的H.264副本，输出到CourseVideos/web-compatible，原文件保留；脚本完成后生成对应映射。

播放器支持倍速、拖动、全屏、每分集续播和时间点笔记。切换分集时笔记按其所属视频跳转；全部分集播放结束后才自动标记整节已学，另保留手动自报。播放结束不等于知识掌握。视频来源由教学管理侧配置，学生端不提供关联视频或选择本地文件的编辑控件；原站播放器仅用于没有本地源的资源。

笔记、播放位置和自报已学标记保存在按账号隔离的localStorage键中，并可与服务端 `learning_records` 表同步；教师端看不到学生私人笔记。学习记录不进入账号审计。

课程前提为已有C#基础，采用按章实例＋开放期末大作业，以3D为主。首课关联现有Unity2021的3D小球基础实验；3D金币拾取及其他实训仍待配置。统一20动词事件契约位于 `contracts/learning-events.mjs`；事件现已通过 `POST /api/teaching/events` 落库（带幂等键，按账号与班级隔离）。量规批阅、班级下发、目标达成矩阵、预警干预、课程思政证据及AI功能属于后续阶段；AI能力按当前要求暂不实现。

## 视频清单导入

`video-library.mjs` 为冻结的分集元数据，`tools/build-video-library.mjs` 可从本机已缓存的公开元数据重新生成模块与交付清单。旧数据库执行 `node CoursePortal/tools/attach-course-videos.mjs`：先完整备份SQLite，仅补空列表；显式加 `--merge-collected` 会保留现有条目并追加缺失ID，保留直链、课时ID、教学目标和发布快照，不自动发布。当前实际草稿已完成两次备份和导入，rev5；用户预览服务重启后使用最新清单。

## 学生端与教师端入口

统一入口为 http://127.0.0.1:8090/login.html，选择学生端或教师端后使用对应账号登录。助教及管理员归入教学管理侧，管理员进入账号管理页面。入口选择由后端按真实账号角色校验，不赋予额外权限。学生首页和视频页不显示教师、管理员或视频源编辑入口；管理侧也没有直接切换学生端的导航，切换账号从退出登录返回统一入口。

匿名访问学习/管理页面会返回登录；学生直接访问教师或管理员页面仍返回登录，教师访问普通学习页面返回自己的工作台。教师为检查课程而打开的已授权草稿预览继续保留，权限由课程成员校验。播放视频和笔记记录机制保持，教学班、任务评分等仍待新教师规范。

## 实操入口与逐单元实验规划

学生侧第三项实操实验、首页实验按钮现统一进入/lab/。原问题为8088独立服务未启动；现由课程服务直接提供已存在的Unity2021 WebGL构建，白名单仅包含Build/Web发布资源，不开放Unity项目文件。实验HTML需要学生登录，实验所需动态代码策略仅限/lab路径。

现有原型已验证创建地面/小球、运行、停止恢复、保存和刷新恢复。本轮没有新增13套实验；完整规划位于D:/unity/outputs/Unity课程-逐单元实验规划.md及同名JSON，12个必修单元各1实验，另1选学。建议实操20学时纳入44教学学时，不改变48学时总量。多实验上线前须落实实验ID/版本及账号存档隔离。

旧8088与新8090是不同浏览器存储来源，旧实验记录未删除但不会自动跨来源迁移；已有课程笔记和视频进度不受影响。
